# 云一朵 · 医药（中西医结合辨证论治 Skill）

一个中西医结合的**辨证论治咨询技能**（Doubao / 豆包办公 Agent Skill），将中医古籍辨证体系与现代医学辨病相结合，输出四方面调治方案。

## 功能

用户描述身体症状（如"头痛""失眠""胃痛""咳嗽""乏力"等）时使用。进入技能先提示"请输入症状"；随后基于中医古籍与现代医学教材综合辨证，判定病症与证型，逐项注明所依据的书名；依次给出**运动（导引）、针灸、吃药（方剂）、饮食搭配**四方面调治方案，并提示起居饮食生活注意事项。

## 每次回答的流程（五步）

1. **提示输入症状**（若已给出则直接进入诊断）
2. **综合辨证诊断**：西医辨病 + 中医辨证，标注依据书名
3. **四方面调治方案**：运动（导引）/ 针灸 / 吃药（方剂）/ 饮食搭配
4. **起居饮食注意事项**
5. **免责声明**（每次必附）

## 使用方式

将本 Skill 目录放入您所用 Agent 的 skill 根目录（如 `~/.doubao/agent_mode/workspace/.user_skills/`）即可被加载。

## 安全与治则

- 辨证为先，禁止"见症套方"
- 经方为主、时方为辅
- 剂量严谨、炮制明确、禁忌必查（十八反十九畏）
- **危险信号优先**：急性危重症先引导就医
- **不替代面诊**：四诊不全不作绝对诊断

## 免责声明

本技能基于中医古籍与现代医学教材的综合整理，仅供健康科普与生活方式参考，**不构成医疗诊断、处方或个体化治疗建议**。身体不适请咨询执业医师/中医师；急性危重症请立即就医。
