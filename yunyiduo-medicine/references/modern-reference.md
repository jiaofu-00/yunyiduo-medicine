# 云一朵·医药 · 现代医学参考（鉴别诊断 / 危险信号 / 就医指征）

> 依据《临床诊断学》（第4版2024）《实用内科学》《内科疾病鉴别诊断学》等现代医学教材，用于：
> 1. **危险信号甄别**：判断症状是否属于需立即就医的急性危重症。
> 2. **现代辨病**：给出可能的西医病名与关键鉴别点。
> 3. **就医指征**：提示何时应前往医院做现代医学检查，中西医结合诊治。

---

## 一、急性危重症危险信号（必先就医，勿延误）

出现以下任一情况，**立即拨打急救电话或前往急诊，本技能仅作科普，不作为延误就医的依据**：

| 系统 | 危险信号 | 提示急症 |
|---|---|---|
| **心血管** | 突发剧烈胸痛（压榨样、持续不缓解）、大汗、呼吸困难、濒死感 | 急性心梗、主动脉夹层 |
| **脑血管** | 突发言语不清、口眼歪斜、单侧肢体无力麻木、剧烈头痛、意识改变 | 脑卒中（中风） |
| **呼吸** | 突发严重呼吸困难、喘憋、口唇紫绀 | 哮喘急性发作、肺栓塞、气胸 |
| **出血** | 呕血、黑便量大、咯血、鼻出血不止 | 消化道/呼吸道出血 |
| **腹部** | 剧烈腹痛拒按、板状腹、腹肌紧张、伴发热 | 急腹症（阑尾炎、胰腺炎、穿孔） |
| **神经** | 高热+抽搐（惊厥）、意识模糊、昏迷 | 脑炎、高热惊厥、休克 |
| **休克** | 面色苍白、冷汗、脉细速、血压下降 | 各种原因休克 |
| **中毒** | 药物过量、疑似中毒 | 急救处理 |

**处理原则**：上述情况**以现代医学急诊处置为先**，辨证论治仅作后续调养参考。

## 二、常见症状的现代辨病与鉴别要点

| 症状 | 需鉴别的西医病名 | 关键鉴别点 | 建议检查 |
|---|---|---|---|
| **头痛** | 紧张性头痛/偏头痛/高血压/颅内占位 | 是否进行性加重、有无神经体征、血压 | 血压测量、头颅CT（必要时） |
| **失眠** | 原发性失眠/焦虑/抑郁/睡眠呼吸暂停 | 伴随情绪、晨起状态、打鼾 | 心理量表、睡眠监测 |
| **胃痛/反酸** | 胃炎/消化性溃疡/胃食管反流/功能消化不良 | 空腹vs餐后、反酸、黑便、体重下降 | 胃镜、幽门螺杆菌 |
| **咳嗽** | 上呼吸道感染/支气管炎/哮喘/肺炎 | 痰色、发热、病程、是否喘息 | 胸片、血常规 |
| **胸痛** | 心绞痛/心梗/肋软骨炎/焦虑 | 活动诱发、放射痛、出汗、心电图 | 心电图、心肌酶、冠脉CTA |
| **心悸** | 心律失常/甲亢/贫血/焦虑 | 发作方式、甲状腺、血常规 | 心电图、动态心电图、甲功 |
| **乏力** | 贫血/甲减/糖尿病/慢性疲劳/抑郁 | 血常规、血糖、甲功、情绪 | 血常规、甲功、血糖 |
| **眩晕** | 耳石症/梅尼埃/高血压/贫血/椎基底动脉供血不足 | 体位性、耳鸣、血压 | 前庭功能、血压、颈椎影像 |
| **关节痛** | 骨关节炎/类风湿/痛风 | 晨僵、红肿热、血尿酸、类风湿因子 | 血尿酸、类风湿因子、关节X线 |
| **水肿** | 肾病/心衰/甲减/肝病 | 部位、凹陷性、伴发症状 | 肾功能、尿常规、心脏彩超 |
| **腹泻** | 肠炎/肠易激/感染性腹泻 | 次数、便血、发热、脱水 | 便常规 |
| **月经不调** | 内分泌失调/多囊卵巢/子宫肌瘤 | 周期、量、伴发症状 | 妇科B超、性激素 |
| **高血压** | 原发性/继发性高血压 | 多次测量、年龄、家族史 | 血压监测、肾功能 |

## 三、慢性病的中西医结合调养要点

| 慢性病 | 现代医学要点（依据） | 中医辨证参考 |
|---|---|---|
| **高血压** | 低盐、规律服药、监测血压（《临床药物治疗学》） | 肝阳上亢/阴虚阳亢 → 平肝潜阳（天麻钩藤饮） |
| **糖尿病** | 血糖控制、饮食管理、规律用药（《临床药物治疗学》） | 消渴 → 滋阴清热（六味地黄丸、玉女煎） |
| **高血脂** | 低脂饮食、他汀类按需（《新编药物学》） | 痰湿/血瘀 → 化痰活血（化痰祛瘀方） |
| **痛风** | 低嘌呤饮食、急性期抗炎（《实用内科学》） | 湿热下注 → 清热利湿（四妙散、宣痹汤） |
| **慢性胃炎** | 胃镜随访、根除幽门螺杆菌 | 脾胃虚寒/肝胃不和 → 温中/疏肝 |
| **失眠** | 睡眠卫生、认知行为治疗 | 心脾两虚/阴虚火旺 → 养心安神 |

> 以上仅供参考，**慢性病用药请遵医嘱，勿自行停药或换药**；中医辨证可作辅助调养，与西医治疗互补（《医学衷中参西录》主张中西汇通）。

## 四、就医指征（何时应去医院）

建议就医的情况：
1. 症状**持续不缓解**（如发热超过3天、咳嗽超过2周、胃痛反复）
2. 症状**进行性加重**或出现上述危险信号
3. 出现**不明原因的体重下降、持续低热、淋巴结肿大**
4. 40岁以上新发症状，或原有症状性质改变
5. 自我调理2周无效
6. 任何**急性剧烈疼痛、出血、呼吸困难**

---

## 五、中西医结合总原则

1. **急性危重→西医优先**：急症先急诊处置。
2. **慢性调理→中西医互补**：西医诊断明确病名，中医辨证调体质，二者并行（《医学衷中参西录》中西汇通思想）。
3. **用药不冲突**：中药与西药同服须咨询医师，避免相互作用（查《药典·临床用药须知》）。
4. **不自行停药**：长期服用的降压/降糖等西药，调整须遵医嘱。
