# 云一朵·医药 · 常见证候库（症状 → 证型 → 主方 → 依据）

> 本库为辨证主检索表：**按症状定位证型 → 确定主方 → 标注依据书名**。回答时必须引用对应书名。方剂剂量为现代常用参考量（成人），具体以执业医师面诊为准；古方原量见《伤寒论》《金匮要略》原文。

## 一、外感篇（感冒·发烧·咳嗽·鼻塞）

### 1. 风寒感冒
- 症状：恶寒重、发热轻、无汗、头身痛、鼻塞流清涕、咳痰稀白、舌淡苔薄白、脉浮紧
- 证型：风寒束表证
- 主方：**麻黄汤**（《伤寒论》第35条）；偏虚者用**桂枝汤**（《伤寒论》第12条）；夹湿用**九味羌活汤**（《此事难知》）
- 依据：《伤寒论》《温病条辨》

### 2. 风热感冒
- 症状：发热重、恶寒轻、汗出、咽痛、口渴、痰黄稠、舌尖红苔薄黄、脉浮数
- 证型：风热犯表证
- 主方：**银翘散**（《温病条辨》）；咽痛加**桑菊饮**（《温病条辨》）
- 依据：《温病条辨》《温病条辨·上焦篇》

### 3. 暑湿感冒
- 症状：身热、头身困重、胸闷脘痞、呕吐泄泻、舌苔白腻、脉濡
- 证型：暑湿困表证
- 主方：**藿香正气散**（《太平惠民和剂局方》）
- 依据：《太平惠民和剂局方》《温病条辨》

### 4. 气虚感冒（反复感冒）
- 症状：恶寒发热不甚、反复发作、自汗、气短乏力、舌淡苔白、脉浮无力
- 证型：气虚外感证
- 主方：**玉屏风散**（《世医得效方》）合**参苏饮**（《太平惠民和剂局方》）
- 依据：《世医得效方》《太平惠民和剂局方》

### 5. 咳嗽（风寒束肺）
- 症状：咳嗽声重、痰白稀、鼻塞流涕、无汗、舌苔薄白
- 证型：风寒束肺证
- 主方：**三拗汤**（《太平惠民和剂局方》）、**止嗽散**（《医学心悟》）
- 依据：《太平惠民和剂局方》《医学心悟》

### 6. 咳嗽（痰热壅肺）
- 症状：咳嗽气促、痰黄稠难咳、口渴、舌红苔黄腻、脉滑数
- 证型：痰热壅肺证
- 主方：**清金化痰汤**（《统旨方》）、**麻杏石甘汤**（《伤寒论》）
- 依据：《伤寒论》《医学心悟》

### 7. 咳嗽（肺阴虚）
- 症状：干咳少痰、痰中带血丝、咽干口燥、潮热盗汗、舌红少苔、脉细数
- 证型：肺阴虚证
- 主方：**沙参麦冬汤**（《温病条辨》）、**百合固金汤**（《医方集解》）
- 依据：《温病条辨》《医方集解》

## 二、头面篇（头痛·头晕·眩晕）

### 1. 头痛（风寒头痛）
- 症状：头痛连项背、恶风畏寒、遇风加重、舌淡苔白
- 证型：风寒头痛证
- 主方：**川芎茶调散**（《太平惠民和剂局方》）
- 依据：《太平惠民和剂局方》《证治准绳》

### 2. 头痛（肝阳上亢）
- 症状：头胀痛、两侧太阳穴为主、心烦易怒、面红目赤、口苦、舌红苔黄、脉弦数
- 证型：肝阳上亢证
- 主方：**天麻钩藤饮**（《杂病诊治新义》）、**龙胆泻肝汤**（《医方集解》）
- 依据：《黄帝内经·素问·至真要大论》《医方集解》

### 3. 头痛（气血两虚）
- 症状：头痛绵绵、劳累后加重、神疲乏力、面色无华、心悸、舌淡、脉细弱
- 证型：气血两虚证
- 主方：**八珍汤**（《瑞竹堂经验方》）
- 依据：《瑞竹堂经验方》《医学衷中参西录》

### 4. 头晕/眩晕（痰湿中阻）
- 症状：眩晕、头重如裹、胸闷恶心、食少多寐、苔白腻、脉濡滑
- 证型：痰湿中阻证
- 主方：**半夏白术天麻汤**（《医学心悟》）
- 依据：《医学心悟》《脾胃论》

### 5. 头晕/眩晕（肝阳上亢）
- 症状：眩晕耳鸣、头胀痛、急躁易怒、失眠多梦、血压高、舌红、脉弦
- 证型：肝阳上亢证
- 主方：**天麻钩藤饮**（《杂病诊治新义》）
- 依据：《黄帝内经》《杂病诊治新义》；现代辨病参考《临床诊断学》（高血压）

### 6. 头晕/眩晕（肾精不足）
- 症状：眩晕久作、腰膝酸软、耳鸣、健忘、发脱齿摇
- 证型：肾精不足证
- 主方：**六味地黄丸**（《小儿药证直诀》）、**左归丸**（《景岳全书》）
- 依据：《小儿药证直诀》《景岳全书》

## 三、心神篇（失眠·多梦·健忘）

### 1. 失眠（肝郁化火）
- 症状：入睡困难、烦躁易怒、口干口苦、目赤、舌红苔黄、脉弦数
- 证型：肝郁化火证
- 主方：**龙胆泻肝汤**（《医方集解》）
- 依据：《医方集解》《黄帝内经》

### 2. 失眠（心脾两虚）
- 症状：多梦易醒、心悸健忘、神疲食少、面色少华、舌淡苔薄、脉细弱
- 证型：心脾两虚证
- 主方：**归脾汤**（《济生方》/《正体类要》）
- 依据：《济生方》《正体类要》

### 3. 失眠（阴虚火旺）
- 症状：心烦不寐、心悸不安、头晕耳鸣、五心烦热、口燥咽干、舌红少苔、脉细数
- 证型：阴虚火旺证
- 主方：**黄连阿胶汤**（《伤寒论》）、**天王补心丹**（《摄生秘剖》）
- 依据：《伤寒论》《摄生秘剖》

### 4. 失眠（痰热扰心）
- 症状：失眠多梦、胸闷脘痞、泛恶嗳气、舌红苔黄腻、脉滑数
- 证型：痰热扰心证
- 主方：**黄连温胆汤**（《六因条辨》）
- 依据：《六因条辨》《温病条辨》

### 5. 健忘（心肾不交/肾精亏虚）
- 症状：健忘、腰膝酸软、头晕耳鸣、失眠
- 证型：肾精亏虚、心肾不交证
- 主方：**天王补心丹**（《摄生秘剖》）、**孔圣枕中丹**（《备急千金要方》）
- 依据：《摄生秘剖》《千金要方》

## 四、脾胃篇（胃痛·胃胀·反酸·腹泻·便秘）

### 1. 胃痛（寒邪犯胃）
- 症状：胃痛暴作、恶寒喜暖、得温则减、口不渴、舌淡苔白、脉弦紧
- 证型：寒邪犯胃证
- 主方：**良附丸**（《良方集腋》）、**吴茱萸汤**（《伤寒论》）
- 依据：《伤寒论》《良方集腋》

### 2. 胃痛（肝气犯胃）
- 症状：胃脘胀痛、连及两胁、嗳气、每因情志不畅加重、舌苔薄白、脉弦
- 证型：肝气犯胃证
- 主方：**柴胡疏肝散**（《景岳全书》）
- 依据：《景岳全书》《太平惠民和剂局方》

### 3. 胃痛（脾胃虚寒）
- 症状：胃痛隐隐、喜温喜按、空腹痛甚、得食则减、泛吐清水、神疲乏力、手足不温、舌淡苔白、脉虚弱
- 证型：脾胃虚寒证
- 主方：**黄芪建中汤**（《金匮要略》）、**理中汤**（《伤寒论》）
- 依据：《金匮要略》《伤寒论》

### 4. 反酸（肝胃不和/胃热）
- 症状：泛酸嘈杂、嗳气、口苦、苔黄
- 证型：肝胃郁热证
- 主方：**左金丸**（《丹溪心法》）、**乌贝散**（经验方）
- 依据：《丹溪心法》《本草纲目》

### 5. 腹泻（脾虚湿盛）
- 症状：大便溏泄、食少腹胀、神疲乏力、舌淡苔白腻、脉细弱
- 证型：脾虚湿盛证
- 主方：**参苓白术散**（《太平惠民和剂局方》）
- 依据：《太平惠民和剂局方》《脾胃论》

### 6. 腹泻（脾肾阳虚·五更泻）
- 症状：黎明前腹痛泄泻、完谷不化、畏寒肢冷、腰膝酸软、舌淡苔白、脉沉迟
- 证型：脾肾阳虚证
- 主方：**四神丸**（《内科摘要》）
- 依据：《内科摘要》《金匮要略》

### 7. 便秘（热秘）
- 症状：大便干结、腹胀腹痛、面赤身热、口干口臭、舌红苔黄燥、脉滑数
- 证型：肠胃积热证
- 主方：**麻子仁丸**（《伤寒论》）、**大承气汤**（《伤寒论》）
- 依据：《伤寒论》

### 8. 便秘（气秘）
- 症状：大便干结、欲便不得、嗳气、胸胁痞满、苔薄腻、脉弦
- 证型：气机郁滞证
- 主方：**六磨汤**（《世医得效方》）
- 依据：《世医得效方》《景岳全书》

### 9. 便秘（虚秘·气血两虚）
- 症状：虽有便意但努挣乏力、大便不干、神疲气怯、面色无华
- 证型：气虚/血虚肠燥证
- 主方：**黄芪汤**（《金匮翼》）、**润肠丸**（《沈氏尊生书》）
- 依据：《金匮翼》《沈氏尊生书》

## 五、心系篇（心悸·胸闷·胸痛）

### 1. 心悸（心脾两虚）
- 症状：心悸气短、头晕目眩、失眠健忘、神疲乏力、面色无华、舌淡、脉细弱
- 证型：心脾两虚证
- 主方：**归脾汤**（《济生方》）
- 依据：《济生方》《正体类要》

### 2. 心悸（阴虚火旺）
- 症状：心悸易惊、心烦失眠、五心烦热、盗汗、舌红少津、脉细数
- 证型：阴虚火旺证
- 主方：**天王补心丹**（《摄生秘剖》）、**黄连阿胶汤**（《伤寒论》）
- 依据：《摄生秘剖》《伤寒论》

### 3. 心悸（心血瘀阻）
- 症状：心悸不安、胸闷不舒、心痛时作、痛如针刺、唇甲青紫、舌紫暗有瘀斑、脉涩或结代
- 证型：心血瘀阻证
- 主方：**血府逐瘀汤**（《医林改错》）
- 依据：《医林改错》《金匮要略》

### 4. 胸痛（胸痹·痰浊闭阻）
- 症状：胸闷如窒而痛、气短喘促、肢体沉重、痰多、苔浊腻、脉滑
- 证型：痰浊闭阻证
- 主方：**瓜蒌薤白半夏汤**（《金匮要略》）
- 依据：《金匮要略·胸痹心痛短气病脉证治》

### 5. 胸痛（气滞血瘀）
- 症状：胸部刺痛固定、入夜尤甚、胸闷气短、舌紫暗、脉涩
- 证型：气滞血瘀证
- 主方：**血府逐瘀汤**（《医林改错》）
- 依据：《医林改错》

> ⚠️ **危险信号**：胸痛若为突发、剧烈、持续不缓解，或伴大汗、呼吸困难、恶心，须立即就医（参照《临床诊断学》心绞痛/心梗鉴别），勿延误（见 modern-reference.md）。

## 六、肢体经络篇（腰痛·关节痛·痹证）

### 1. 腰痛（肾虚）
- 症状：腰痛绵绵、酸软无力、劳累后加重、喜揉按、夜尿频、舌淡、脉沉细
- 证型：肾虚腰痛证
- 主方：**右归丸**（肾阳虚，《景岳全书》）、**左归丸**（肾阴虚，《景岳全书》）、**青娥丸**（《太平惠民和剂局方》）
- 依据：《景岳全书》《太平惠民和剂局方》

### 2. 腰痛（寒湿痹阻）
- 症状：腰部冷痛重着、阴雨天加重、转侧不利、舌淡苔白腻、脉沉缓
- 证型：寒湿腰痛证
- 主方：**独活寄生汤**（《备急千金要方》）
- 依据：《千金要方》《金匮要略》

### 3. 关节痛/痹证（风寒湿痹）
- 症状：肢体关节疼痛、遇寒加重、得温则减、重着肿胀、屈伸不利、苔白腻
- 证型：风寒湿痹证
- 主方：**蠲痹汤**（《医学心悟》）、**独活寄生汤**（《千金要方》）
- 依据：《医学心悟》《千金要方》

### 4. 关节痛（风湿热痹）
- 症状：关节红肿热痛、屈伸不利、发热、口渴、苔黄燥、脉滑数
- 证型：风湿热痹证
- 主方：**白虎加桂枝汤**（《金匮要略》）、**宣痹汤**（《温病条辨》）
- 依据：《金匮要略》《温病条辨》

### 5. 痛风（湿热下注）
- 症状：足趾关节红肿热痛、夜间加剧、舌红苔黄腻、血尿酸高
- 证型：湿热下注证
- 主方：**四妙散**（《成方便读》）、**宣痹汤**（《温病条辨》）
- 依据：《成方便读》《温病条辨》；现代辨病参考《实用内科学》（痛风）

## 七、虚劳篇（乏力·多汗·怕冷·易疲劳）

### 1. 乏力（气虚）
- 症状：神疲乏力、少气懒言、动则气短、自汗、舌淡、脉虚
- 证型：气虚证（脾气虚为主）
- 主方：**四君子汤**（《太平惠民和剂局方》）、**补中益气汤**（《脾胃论》）
- 依据：《太平惠民和剂局方》《脾胃论》

### 2. 怕冷（阳虚）
- 症状：畏寒肢冷、腰膝酸软、精神萎靡、夜尿多、舌淡胖、脉沉迟无力
- 证型：肾阳虚证
- 主方：**金匮肾气丸**（《金匮要略》）、**右归丸**（《景岳全书》）
- 依据：《金匮要略》《景岳全书》

### 3. 自汗（气虚卫外不固）
- 症状：时时汗出、动则更甚、易感冒、神疲乏力、舌淡、脉虚弱
- 证型：肺卫气虚证
- 主方：**玉屏风散**（《世医得效方》）
- 依据：《世医得效方》《丹溪心法》

### 4. 盗汗（阴虚）
- 症状：寐中汗出、醒后汗止、五心烦热、潮热、舌红少苔、脉细数
- 证型：阴虚火旺证
- 主方：**当归六黄汤**（《兰室秘藏》）
- 依据：《兰室秘藏》《医宗金鉴》

### 5. 血虚（面色萎黄）
- 症状：面色苍白或萎黄、头晕眼花、心悸失眠、手足麻木、月经量少、舌淡、脉细
- 证型：血虚证
- 主方：**四物汤**（《太平惠民和剂局方》）、**当归补血汤**（《内外伤辨惑论》）
- 依据：《太平惠民和剂局方》《内外伤辨惑论》

## 八、妇科篇（月经不调·痛经·带下·更年期）

### 1. 月经不调（肝郁）
- 症状：月经先后不定期、量或多或少、胸胁乳房胀痛、嗳气、舌苔薄白、脉弦
- 证型：肝气郁结证
- 主方：**逍遥散**（《太平惠民和剂局方》）、**柴胡疏肝散**（《景岳全书》）
- 依据：《太平惠民和剂局方》《景岳全书》《傅青主女科》

### 2. 月经不调（肾虚）
- 症状：月经后期量少、色淡质稀、腰膝酸软、头晕耳鸣、舌淡、脉沉细
- 证型：肾精亏虚证
- 主方：**六味地黄丸**（《小儿药证直诀》）、**归肾丸**（《景岳全书》）
- 依据：《小儿药证直诀》《景岳全书》

### 3. 痛经（寒凝血瘀）
- 症状：经前或经期小腹冷痛、得热则减、经色暗有血块、畏寒肢冷、舌紫暗、脉沉紧
- 证型：寒凝血瘀证
- 主方：**少腹逐瘀汤**（《医林改错》）
- 依据：《医林改错》《傅青主女科》

### 4. 痛经（气滞血瘀）
- 症状：经前小腹胀痛拒按、经色紫暗有块、块下痛减、胸胁乳房胀痛、脉弦涩
- 证型：气滞血瘀证
- 主方：**膈下逐瘀汤**（《医林改错》）
- 依据：《医林改错》《妇人良方》

### 5. 带下（脾虚湿盛）
- 症状：带下量多、色白质稀无臭、倦怠乏力、食少便溏、舌淡苔白腻、脉缓弱
- 证型：脾虚带下证
- 主方：**完带汤**（《傅青主女科》）
- 依据：《傅青主女科》《妇人大全良方》

### 6. 更年期（肾阴不足/肝郁化火）
- 症状：烘热汗出、潮热面红、心烦易怒、失眠、月经紊乱
- 证型：肾阴虚、肝阳上亢证
- 主方：**六味地黄丸**（《小儿药证直诀》）、**丹栀逍遥散**（《内科摘要》）
- 依据：《小儿药证直诀》《内科摘要》

## 九、情志篇（情绪低落·焦虑·郁证）

### 1. 郁证（肝气郁结）
- 症状：情志抑郁、胸胁胀满、善太息、嗳气、咽部异物感（梅核气）、脉弦
- 证型：肝气郁结证
- 主方：**逍遥散**（《太平惠民和剂局方》）、**柴胡疏肝散**（《景岳全书》）；梅核气用**半夏厚朴汤**（《金匮要略》）
- 依据：《太平惠民和剂局方》《景岳全书》《金匮要略》

### 2. 郁证（痰气郁结）
- 症状：咽中如有物阻、吐之不出吞之不下、胸胁满闷、苔白腻、脉弦滑
- 证型：痰气郁结证
- 主方：**半夏厚朴汤**（《金匮要略》）
- 依据：《金匮要略·妇人杂病脉证并治》

### 3. 郁证（心神失养·脏躁）
- 症状：精神恍惚、心神不宁、悲伤欲哭、时时欠伸、舌淡红、脉细
- 证型：心脾两虚、心神失养证（脏躁）
- 主方：**甘麦大枣汤**（《金匮要略》）
- 依据：《金匮要略·妇人杂病脉证并治》

### 4. 焦虑（心胆气虚）
- 症状：心悸善恐、坐卧不安、多思虑、易受惊、气短乏力、舌淡、脉细
- 证型：心胆气虚证
- 主方：**安神定志丸**（《医学心悟》）
- 依据：《医学心悟》

## 十、其他篇（水肿·耳鸣·口疮·便秘·皮肤）

### 1. 水肿（脾肾阳虚）
- 症状：全身水肿、腰以下为甚、按之凹陷、畏寒肢冷、腹胀便溏、舌淡胖、脉沉迟
- 证型：脾肾阳虚证
- 主方：**真武汤**（《伤寒论》）、**济生肾气丸**（《济生方》）
- 依据：《伤寒论》《济生方》

### 2. 耳鸣（肝火上扰 / 肾虚）
- 症状：突发耳鸣如潮、头胀痛（肝火）；久鸣如蝉、腰膝酸软（肾虚）
- 证型：肝火上扰证 / 肾精亏虚证
- 主方：**龙胆泻肝汤**（肝火，《医方集解》）；**耳聋左慈丸**（肾虚）
- 依据：《医方集解》《小儿药证直诀》

### 3. 口疮（心脾积热）
- 症状：口腔溃疡红肿灼痛、口渴、口臭、心烦、舌红苔黄、脉数
- 证型：心脾积热证
- 主方：**导赤散**（《小儿药证直诀》）、**凉膈散**（《太平惠民和剂局方》）
- 依据：《小儿药证直诀》《太平惠民和剂局方》

### 4. 皮肤瘙痒（血虚风燥）
- 症状：皮肤干燥瘙痒、抓后血痕、脱屑、血虚、舌淡、脉细
- 证型：血虚风燥证
- 主方：**四物消风饮**（《医宗金鉴》）、**消风散**（《外科正宗》）
- 依据：《医宗金鉴》《外科正宗》

## 用方注意事项（铁律）

1. 本方库所列主方为**常见证型对应方**，实际应用须结合个体体质、兼证与四诊信息调整，**禁止机械套用**。
2. 剂量为现代成人常用参考量，**孕妇、儿童、老人、体弱者须减量或改用安全方**，具体以执业医师为准。
3. 十八反、十九畏（《本草纲目》）与妊娠禁忌药必须查对。
4. 症状符合急性危重症（剧烈胸痛、大出血、昏迷、中风、高热惊厥、呼吸困难）时**先引导立即就医**（见 modern-reference.md）。
5. 长期不愈或症状加重者建议就医做现代医学检查，中西医结合诊治。
