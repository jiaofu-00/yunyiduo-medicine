# 云一朵·医药 · 辨证论治框架

> 中西医结合辨证 = **西医辨病（现代教材）+ 中医辨证（古籍体系）**，二者并行互参，最终给出病症、证型与依据书名。

---

## 一、辨证总流程（诊断七步）

```
输入症状
   │
1. 西医辨病：按《临床诊断学》《实用内科学》判断可能病名
   │
2. 危险信号甄别：查 modern-reference.md → 符合急性危重症则先引导就医
   │
3. 中医辨证层级判定（由粗到精）：
   ├─ 八纲辨证（阴阳表里虚实寒热）←《景岳全书》《医学心悟》《黄帝内经》
   ├─ 六经辨证（太阳/阳明/少阳/太阴/少阴/厥阴）←《伤寒论》《金匮要略》
   ├─ 脏腑辨证（心肝脾肺肾+六腑）←《黄帝内经·素问》《金匮要略》《笔花医镜》
   ├─ 卫气营血/三焦辨证（外感热病）←《温病条辨》《温热论》《湿热病篇》
   └─ 气血津液辨证（气虚/血虚/血瘀/痰湿）←《医林改错》《血证论》《黄帝内经》
   │
4. 确定证型 → 查 zheng-hou-library.md 匹配症状→证型→主方
   │
5. 拟定治法（治则）→ 给四方面方案（运动/针灸/吃药/饮食）
   │
6. 标注依据书名 → 逐项注明出处
   │
7. 附起居注意事项 + 免责声明
```

## 二、八纲辨证（总纲）

| 八纲 | 判定要点 | 依据书目 |
|---|---|---|
| **阴/阳** | 总纲；阳虚（畏寒肢冷、精神萎靡、脉沉微）；阴虚（潮热盗汗、五心烦热、舌红少苔） | 《黄帝内经·阴阳应象大论》《景岳全书》 |
| **表/里** | 表证（恶寒发热、脉浮）；里证（不恶寒反恶热或但寒、脏腑症状） | 《伤寒论》《温病条辨》 |
| **寒/热** | 寒证（恶寒喜暖、面白、舌淡苔白、脉迟）；热证（恶热喜凉、面赤、舌红苔黄、脉数） | 《黄帝内经》《景岳全书》 |
| **虚/实** | 虚证（久病体弱、脉无力）；实证（新病体壮、脉有力） | 《内经》《伤寒论》 |

**寒热真假鉴别**（《景岳全书》《伤寒论》）：
- 真寒假热：面红如妆、口渴不欲饮喜热饮、小便清长、舌淡、脉虚。
- 真热假寒：四肢厥冷但胸腹灼热、口渴喜冷饮、小便短赤、舌红、脉沉数有力。
- 判断口诀：**"以脉象沉取、舌象为本，从小便与口渴辨真假"**（参考《医宗金鉴·四诊心法要诀》）。

## 三、六经辨证（外感病 + 部分内伤）

依据《伤寒论》《金匮要略》。六经传变：太阳→阳明/少阳→太阴→少阴→厥阴。

| 六经 | 提纲主证 | 主方 | 依据 |
|---|---|---|---|
| **太阳病** | 脉浮、头项强痛而恶寒 | 桂枝汤（有汗）/麻黄汤（无汗） | 《伤寒论》 |
| **阳明病** | 胃家实、身热汗出、不恶寒反恶热 | 白虎汤（经证）/承气汤（腑证） | 《伤寒论》 |
| **少阳病** | 口苦咽干目眩、往来寒热、胸胁苦满 | 小柴胡汤 | 《伤寒论》 |
| **太阴病** | 腹满而吐、食不下、自利腹痛 | 理中汤/四逆辈 | 《伤寒论》 |
| **少阴病** | 脉微细、但欲寐、四肢厥冷 | 四逆汤/真武汤 | 《伤寒论》 |
| **厥阴病** | 消渴、气上撞心、心中疼热、饥不欲食 | 乌梅丸/当归四逆汤 | 《伤寒论》 |

**六经快速辨证**：有恶寒+脉浮→太阳；但热不寒→阳明；往来寒热→少阳；腹满自利不渴→太阴；脉微细但欲寐→少阴；寒热错杂→厥阴（《伤寒论》六经提纲）。

## 四、脏腑辨证（内伤杂病主体）

依据《黄帝内经·素问》《金匮要略》《笔花医镜》《医学心悟》。

| 脏腑 | 生理要点 | 常见证型 | 主方示例 |
|---|---|---|---|
| **心** | 主血脉、藏神 | 心血虚/心气虚/心火亢盛/心脉痹阻 | 归脾汤（《济生方》）、天王补心丹（《摄生秘剖》）、炙甘草汤（《伤寒论》） |
| **肝** | 主疏泄、藏血 | 肝气郁结/肝火上炎/肝阳上亢/肝血虚 | 逍遥散（《太平惠民和剂局方》）、龙胆泻肝汤（《医方集解》）、天麻钩藤饮 |
| **脾** | 主运化、统血 | 脾气虚/脾阳虚/湿困脾 | 四君子汤、补中益气汤（《脾胃论》）、参苓白术散（《局方》） |
| **肺** | 主气、司呼吸、宣发肃降 | 肺气虚/风热犯肺/痰热壅肺 | 玉屏风散、桑菊饮/银翘散（《温病条辨》）、麻杏石甘汤（《伤寒论》） |
| **肾** | 主藏精、主水、纳气 | 肾阳虚/肾阴虚/肾精不足 | 肾气丸（《金匮要略》）、六味地黄丸（《小儿药证直诀》）、左归丸/右归丸（《景岳全书》） |
| **胃** | 主受纳腐熟、和降 | 胃阴虚/胃寒/食滞/胃热 | 保和丸（《丹溪心法》）、香砂养胃丸、吴茱萸汤（《伤寒论》） |
| **胆/大肠/小肠/膀胱/三焦** | 六腑传化物 | 胆热/大肠湿热/膀胱湿热等 | 龙胆泻肝汤、白头翁汤（《伤寒论》）、八正散（《局方》） |

## 五、卫气营血辨证（外感温热病）

依据《温热论》（叶天士）《温病条辨》（吴鞠通）《湿热病篇》（薛生白）。

| 层次 | 主证 | 治法要旨 | 代表方 |
|---|---|---|---|
| **卫分** | 发热微恶寒、头痛、口渴、脉浮数 | "在卫汗之可也" | 银翘散、桑菊饮（《温病条辨》） |
| **气分** | 壮热不恶寒、大汗、大渴、脉洪大 | "到气才可清气" | 白虎汤（《伤寒论》）、麻杏石甘汤 |
| **营分** | 身热夜甚、心烦谵语、斑疹隐隐、舌红绛 | "入营犹可透热转气" | 清营汤（《温病条辨》） |
| **血分** | 斑疹紫黑、吐血衄血、躁扰发狂、舌深绛 | "入血直须凉血散血" | 犀角地黄汤（《外台秘要》） |

## 六、气血津液辨证

| 证型 | 要点 | 主方 | 依据 |
|---|---|---|---|
| **气虚** | 乏力、气短、自汗、脉虚 | 四君子汤、补中益气汤 | 《太平惠民和剂局方》《脾胃论》 |
| **血虚** | 面白无华、头晕、心悸、舌淡 | 四物汤、当归补血汤 | 《太平惠民和剂局方》 |
| **血瘀** | 刺痛固定、舌紫暗有瘀点、脉涩 | 血府逐瘀汤 | 《医林改错》 |

## 七、现代辨病要点（西医）

依据《临床诊断学》（第4版2024）《实用内科学》《内科疾病鉴别诊断学》：

| 症状 | 常见西医病名（需鉴别） | 关键鉴别点 |
|---|---|---|
| 头痛 | 紧张性头痛/偏头痛/高血压/颅内病变 | 血压、进行性加重、神经体征 |
| 失眠 | 原发性失眠/焦虑/抑郁症/睡眠呼吸暂停 | 伴随情绪、晨起状态 |
| 胃痛 | 胃炎/消化性溃疡/胃食管反流/功能消化不良 | 空腹vs餐后、反酸、黑便 |
| 咳嗽 | 上呼吸道感染/支气管炎/哮喘/肺炎 | 痰色、发热、病程 |
| 胸痛 | 心绞痛/心肌梗死/肋软骨炎/焦虑 | 活动诱发、放射痛、心电图 |
| 心悸 | 心律失常/甲亢/贫血/焦虑 | 心电图、甲状腺功能、血常规 |
| 乏力 | 贫血/甲减/慢性疲劳/糖尿病/抑郁 | 血常规、血糖、甲功 |
| 关节痛 | 骨关节炎/类风湿/痛风 | 晨僵、红肿热、血尿酸、类风湿因子 |

## 八、辨证与治法对应总表（八法）

依据《医学心悟》（程钟龄"治病八法"）：**汗、吐、下、和、温、清、消、补**。

| 治法 | 适用范围 | 代表方 | 依据 |
|---|---|---|---|
| 汗法 | 表证 | 麻黄汤、桂枝汤、银翘散 | 《伤寒论》《温病条辨》 |
| 下法 | 里实（便秘、燥结） | 大承气汤、麻子仁丸 | 《伤寒论》《金匮要略》 |
| 和法 | 半表半里 | 小柴胡汤、逍遥散 | 《伤寒论》《局方》 |
| 温法 | 里寒 | 四逆汤、理中汤 | 《伤寒论》 |
| 清法 | 里热 | 白虎汤、黄连解毒汤 | 《伤寒论》《外台秘要》 |
| 消法 | 积滞瘀痰 | 保和丸、血府逐瘀汤 | 《丹溪心法》《医林改错》 |
| 补法 | 虚证 | 六味地黄丸、补中益气汤 | 《小儿药证直诀》《脾胃论》 |

> 每次辨证先确定**八法之一或组合**作为治则，再落到具体方剂与四方面调治方案。
