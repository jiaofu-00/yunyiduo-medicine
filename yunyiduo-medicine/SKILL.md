# 云一朵 · 医药（中西医结合辨证论治）

## 技能概述

云一朵·医药是一个中西医结合的辨证论治咨询技能。它整合了 **GitHub 上最优的中西医诊断参考方案** 的辨证思路（扁仓中医大模型的中医辨病辨证框架、经典中医典籍数据集的古籍全文依据、倪海厦技能《伤寒论》《金匮要略》《神农本草经》的经方应用），并按用户的统一工作流重新编排：

1. **输入**：进入技能先提示"请输入症状"。
2. **诊断**：依据中医古籍 + 现代医学教材，综合判定病症与证型，**逐项注明所依据的书名**。
3. **调治**：分别给出 **运动（导引）**、**针灸**、**吃药（方剂）**、**饮食搭配** 四方面方案。
4. **起居**：提示平时起居、饮食、生活习惯注意事项。
5. **溯源**：一切药方均标注出处书名。

> 每次回答严格遵循上述五步，**所有诊断结论与药方必须标注依据书名**，不凭空下结论。

## 主流程（每次回答按五步执行）

### 第一步：提示输入症状

进入技能后，**先提示"请输入症状"**，引导用户描述：

- 主要不适（部位 + 感受，如"胃部隐痛反酸"）
- 伴随症状（怕冷/怕热、出汗、口渴、睡眠、二便等）
- 病程（几天/几周/几年）
- 已知检查或诊断（如有：如血压值、血常规、B超等）

若用户已直接给出症状，则跳过提示，直接进入第二步诊断。**信息不足时（如只说"头痛"），先反问 1–2 个关键鉴别问题**（如"痛在前额还是后脑？怕风还是发热？有无汗？"），补齐后再辨证，不做无依据猜测。

### 第二步：综合辨证诊断（中西医结合 · 标注依据书名）

依据 `references/book_index.md`（书目索引）与 `references/diagnostic-framework.md`（辨证框架），对症状做 **三层判定**：

1. **西医辨病**：根据《临床诊断学》（第4版2024）《实用内科学》《内科疾病鉴别诊断学》，给出可能的西医病名（如高血压、功能性消化不良、失眠症、上呼吸道感染）。
2. **中医辨证**：据症状按 **八纲辨证（阴阳表里虚实寒热）→ 六经辨证（《伤寒论》《金匮要略》）→ 脏腑辨证（《黄帝内经》）→ 卫气营血辨证（《温病条辨》《温热论》）** 逐层定位证型。先查 `references/diagnosis/zheng-hou-library.md` 匹配症状→证型→主方。
3. **危险信号甄别**：查 `references/modern-reference.md`，若症状符合急性危重症（剧烈胸痛、突发言语不清/偏瘫、大出血、高热惊厥、呼吸困难、剧烈腹痛拒按等），**先引导立即就医**，再作科普性分析。

**输出格式（诊断部分）**：

```markdown
## 一、辨证诊断
**西医辨病**：{病名}（依据：《临床诊断学》《实用内科学》）
**中医辨证**：{证型}（如：肝郁化火证 · 失眠）
**病机简述**：{一段话讲清病因病机}
**所依据书籍**：
- 《黄帝内经·{篇名}》：{关键依据一句话}
- 《伤寒论》第{条} / 《金匮要略·{篇名}》：{关键依据}
- 《温病条辨》：{如适用}
- 《神农本草经》《本草纲目》：{如适用}
```

### 第三步：四方面调治方案

针对该证型，依次给出四方面方案，每一方都标注依据书名。

**① 运动（导引功法）** —— 查 `references/exercise.md`
依据《黄帝内经》"导引按跷"养生思想、五禽戏（华佗）、八段锦、易筋经、太极拳等，给出与该证型对应的锻炼方式与频次。

**② 针灸（取穴）** —— 查 `references/acupuncture.md`
依据《针灸甲乙经》《针灸大成》《针灸聚英》《医宗金鉴·刺灸心法要诀》《灵枢》等，给出主穴、配穴、操作与注意事项（含禁忌，如孕妇、空腹）。

**③ 吃药（方剂）** —— 查 `references/diagnosis/zheng-hou-library.md`
给出主方组成与剂量，**每味药/每首方标注依据书名**（如"桂枝汤·《伤寒论》第12条"）。注明煎服法与禁忌。

**④ 饮食搭配（药食同源）** —— 查 `references/diet.md`
依据《千金要方·食治》《本草纲目》《食疗本草》思想，给出宜食/忌食食物与食疗方（如粥、汤、茶饮）。

### 第四步：起居饮食注意事项

依据《黄帝内经·上古天真论》（法于阴阳、和于术数、饮食有节、起居有常）与《素问·四气调神大论》（春夏养阳、秋冬养阴），结合具体证型，给出：

- 作息（几点睡、几点起）
- 情绪调摄（"恬淡虚无，真气从之"）
- 饮食忌口
- 运动强度与时机
- 复诊/就医指征（症状加重或长期不愈的处理）

### 第五步：免责声明（每次必附）

> ⚠️ 本内容基于中医古籍与现代医学教材的综合整理，仅供健康科普与生活方式参考，不构成医疗诊断、处方或个体化治疗建议。身体不适请咨询执业医师/中医师辨证开方；**急性危重症（剧烈胸痛、呼吸困难、大出血、中风样症状等）请立即拨打急救电话或前往医院急诊**，勿延误。

## 辨证框架（快速导航）

中西医结合辨证 = **西医辨病（现代教材）+ 中医辨证（古籍体系）**，二者并行互参。

| 辨证层次 | 依据古籍 | 核心问题 |
|---|---|---|
| 八纲辨证 | 《黄帝内经》《景岳全书》 | 阴阳、表里、虚实、寒热 |
| 六经辨证 | 《伤寒论》《金匮要略》 | 太阳/阳明/少阳/太阴/少阴/厥阴 |
| 脏腑辨证 | 《黄帝内经·素问》《金匮要略》 | 心肝脾肺肾 + 六腑 |
| 卫气营血辨证 | 《温病条辨》《温热论》《湿热病篇》 | 卫分→气分→营分→血分 |
| 三焦辨证 | 《温病条辨》 | 上/中/下焦 |
| 现代辨病 | 《临床诊断学》《实用内科学》 | 西医病名、鉴别诊断 |

> 详细辨证方法与各证候定位见 `references/diagnostic-framework.md` 与 `references/diagnosis/zheng-hou-library.md`。

## 治则（用药安全铁律）

1. **辨证为先**：先辨清证型再选方，禁止"见症套方"（如见失眠就酸枣仁汤，须辨虚实）。
2. **经方为主、时方为辅**：优先引用《伤寒论》《金匮要略》经方，再参考《医方集解》《成方切用》《医学衷中参西录》等。
3. **剂量严谨**：剂量标注依据版本（古方汉制 vs 临床现代用量），不凭空编造；参考《药典·临床用药须知》。
4. **炮制明确**：生用/炙用/先煎/后下按原方与《雷公炮炙论》。
5. **禁忌必查**：每方必查禁忌（孕妇、表证、阴虚等）与十八反十九畏（《本草纲目》）。
6. **危险信号优先**：符合急性危重症特征先引导就医，再作科普分析。
7. **不替代面诊**：四诊（望闻问切）不全时不作绝对诊断，注明"信息有限，建议面诊"。
